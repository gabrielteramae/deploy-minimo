rsync + nginx

O mínimo para publicar.

Esta página não passou por GitHub Pages nem por Vercel. O diretório site/ foi copiado com rsync. O nginx só entrega os arquivos.

1. Servir

  1. O mesmo arquivo deste repositório vai em /etc/nginx/conf.d/deploy-minimo.conf. 
    sudo nginx -t && sudo systemctl reload nginx

2. Enviar

  1. Da máquina de trabalho, com SSH já autorizado no servidor. 
    DEPLOY_HOST=exemplo.com DEPLOY_USER=deploy \
DEPLOY_PATH=/var/www/deploy-minimo \
scripts/deploy.sh
Se esta página abriu, o nginx achou o index.html.
